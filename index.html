NeRF Engine

An implementation of Neural Radiance Fields (NeRF) for synthesizing photorealistic 3D scenes from a sparse set of 2D images. Built using PyTorch, this engine leverages Multi-Layer Perceptrons (MLPs) to encode volumetric density and view-dependent color-emittance. Optimized for faster rendering times using positional encoding and stratified sampling techniques.

Computer Vision PyTorch 3D Rendering Deep Learning

A multimodal AI system designed to generate accurate, context-aware captions for video content in real-time. Unique Feature: Includes a specialized model trained to generate captions specifically in the Nepali Language, bridging the gap in local language NLP resources.

NLP Computer Vision CNN-RNN Nepali AI
